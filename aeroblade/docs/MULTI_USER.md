# 多用户测试指南

## 管理员邀请测试者

1. 使用原管理员账号登录，点击顶栏“账号”→“管理用户与邀请码”。
2. 点击“生成邀请码”，复制显示的完整邀请码，分享给最多10名测试者。
3. 每个邀请码有效期7天，最多成功注册10个账号；未过期且仍有名额的邀请码可以撤销。列表不再次显示完整邀请码。
4. 用户列表可禁用或恢复普通账号。禁用撤销其会话并停止该用户任务；保留已有数据。

## 测试者注册与个人模型

点击“登录 / 注册”→“持有邀请码？注册账号”，填写用户名、至少12字符的密码、确认密码及邀请码。用户名不区分大小写。

注册后在“模型配置”填写自己的模型地址、模型名称及 API Key。普通账号仅允许公网 HTTPS 模型地址；账号之间不共享管理员密钥，也不共享配置。服务器保存密钥，但读取配置只返回“已配置”状态。

“账号”中可以修改自己的密码，修改后需要重新登录。首版不提供邮件找回密码。

## 关键数据

- 顶栏“我的数据”可保存当前参数化设计、评估工况和备注；支持载入、重命名与删除。
- 初始设计页的“保存 / 打开对话”可保存对话、草稿与候选方案，并在其他浏览器登录后恢复。
- 每账号最多保存100份设计和50份对话；单份对话最多1 MiB、60条消息。
- 保存是明确操作，不会自动把每次编辑同步到云端。载入会替换当前未保存内容，操作前会提示。
- 个人数据、模型配置和评估目录按用户隔离。退出或切换账号会清空页面中的上一账号数据。
- 不要在对话或备注中粘贴 API Key、密码等秘密；模型密钥只填在专用配置框中。

## 计算权限

当前腾讯云后端是 model-only 模式，没有 OpenFOAM 求解能力。全局 CFD 队列和机器令牌只供管理员使用；普通账号不能查看、控制管理员 CFD 任务。

个人评估任务各自保存。每用户最多2个活动评估任务，服务器总计最多4个；模型调用每用户最多2个、服务器总计最多8个。普通用户的科学计算功能仍取决于服务器安装的数值依赖。

## 数据与升级

旧管理员账号、密码哈希、模型配置及原任务目录保留；首次升级会撤销旧登录会话，请重新登录。

服务器状态默认在 `/var/lib/aeroblade/state.sqlite3`；用户任务在其同级 `users/<user_id>/` 下。模型密钥采用私有文件权限保护，数据库未做静态加密，备份须按敏感数据保管。

升级前停止服务并完整备份私有目录和程序版本；回退时恢复匹配的数据库备份与程序，不让旧程序写入已升级数据库。不要将私有目录、邀请码或数据库上传 GitHub/Vercel。

邀请码升级后，已有邀请码保留原到期时间和撤销状态；历史一次成功注册计为已用1次，总额度变为10次。失败注册不消耗名额，并发注册不会超过上限。
