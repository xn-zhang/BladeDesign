# 网页流场可视化

在宽屏上位于“残差历史”和“求解日志”右侧；窄屏自动排列在其下方。刷新工作台，连接服务并选择一个已完成二维任务即可自动加载。

- 切换速度大小（m/s）、静压（Pa）和温度（K）；不可压缩运动压力按文件维度显示 m²/s²，不误标为 Pa。
- 色标为当前结果实际单元值范围。勾选显示网格可显示单元边线。
- 滚轮缩放、拖动平移、“重置视图”恢复范围；悬停显示原始单元编号、位置及物理量。坐标用 mm，内部几何仍为 m。
- 读取 constant/polyMesh 的 points、faces、owner、neighbour 和 empty 边界，加上最后写入时间目录的 internalField。多边形直接对应真实单元；速度为三分量的欧氏模。
- 不进行跨叶片插值；没有流体单元的位置不着色。只支持 XY 平面的单层二维算例和 ASCII OpenFOAM 文件，上限 60000 个单元。三维或超限数据请下载 VTK。
- 仅完成任务提供 GET /api/jobs/{id}/flow。接口仍需 Bearer 鉴权和允许的 Origin，客户端不能指定任意文件路径。
- 切换任务、断开连接或加载失败会清空云图；过期响应会丢弃，刷新任务可重试。
- 云图绑定计算任务的几何快照，不随左侧尚未提交的设计修改。未确认收敛的完成任务会保留提示；有云图不代表工程精度已经验证。
