# Pritchard 模型更新方案

依据 L. J. Pritchard (1985), ASME 85-GT-219，原文图1、图5、式1–16与附录C/E/F/G。

- 11个显式截面参数；半径和叶片数决定节距。入口角使用半楔角约定。
- 三圆弧与两三次多项式，满足C1；尾缘半楔角由闭合约束确定。
- 默认采用图19算例统一换算mm；不启用原FORTRAN根据数值大小猜测输入含义的默认值机制。
- 展宽为独立展示/拉伸设置，不冒充原始11参数中的一项。暂不声称径向多截面优化。
- 旧模型保留独立模块，历史JSON与CFD记录显式标识，禁止静默映射为新参数。
- 新CFD模板适配节距与计算域，旧模板不接受新模型。
- 验证论文示例、闭合/切线/半径约束、拒绝无效轮廓、导入导出、实际网格与求解集成。
