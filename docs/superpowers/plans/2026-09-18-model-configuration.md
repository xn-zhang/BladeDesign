# 真实模型配置与对话接入 Implementation Plan

**Goal:** 初始设计支持用户配置 Chat Completions 兼容服务，完成测试、保存和真实对话转发。
**Architecture:** 原标准库后端增加 ModelService；配置/测试/清除/对话使用已有平台令牌鉴权。前端独立配置弹窗，通用与航发模型各一份配置。密钥只存在服务端进程内存，可通过环境变量启动加载，不进入浏览器存储或导出文件。
**Tech Stack:** Python 标准库 urllib/http.server、原生 JavaScript/CSS、unittest 与 Node test。当前项目目录已更名为 `aeroblade/`。

## 范围与交互

- 初始设计栏新增“模型配置”；平台连接地址/访问令牌与上游 Base URL/API Key 分开展示。
- 可复用已连接 CFD 服务的地址和令牌；未连接时允许单独连接平台后端，不要求 OpenFOAM 就绪。
- 支持两类模型独立保存；字段：Base URL、模型名称、Bearer/无鉴权、API Key、5–120秒超时、可选 JSON 模式。
- 读取配置返回 has_key，绝不回显密钥。空 Key 保留同一地址旧密钥；地址改变须重新输入 Key。
- 测试使用表单草稿发一条短请求，不修改已保存配置；保存才生效。测试可能消耗少量模型额度，界面明确说明。
- 保存后旧初设候选失效；生成中禁用配置入口。配置弹窗关闭时清空输入框中的密钥。
- 后端输出结构化 JSON 给原初设校验器；普通文本只能作为对话，不能转成可应用的几何方案。
- 服务重启清除内存配置；环境变量支持持久部署。浏览器停止只停止等待，不保证上游已取消计费，限制并发和超时。
