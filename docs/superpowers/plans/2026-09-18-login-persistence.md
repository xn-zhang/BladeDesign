# 登录会话与部署改造 Implementation Plan

**Goal:** 用户通过登录使用模型配置和对话，无需填写平台令牌；模型配置跨服务重启保存，并提供 Vercel 前端与独立后端的部署入口。
**Architecture:** Python 标准库 SQLite 保存管理员口令哈希、会话与模型配置；HttpOnly Cookie 加 CSRF 校验；浏览器统一同源 API。独立 CFD 服务保留已有服务令牌接口，同源 CFD 可复用登录。
**Scope:** 单管理员工作台，不包含多租户隔离、注册邮件或外部 OAuth。旧 API Bearer 令牌仅用于机器/独立 CFD 接入。私有数据库包含模型密钥，放在受限数据目录，不进入静态发布或 Git；不宣称加密存储。

- [x] 新增 `bridge/session_store.py`，接入 `server.py` 和 `design_assistant.py`。

部署：本地首次通过受限初始化页面创建管理员；公网后端部署时通过 AEROBLADE_ADMIN_USERNAME/PASSWORD 初始化，并设置 AEROBLADE_PUBLIC_ORIGIN、AEROBLADE_DATA_DIR。Vercel只设置后端地址用于生成代理，不持有供应商密钥。
