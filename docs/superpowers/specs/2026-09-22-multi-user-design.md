# AeroBlade 邀请注册与个人工作区

日期：2026-09-22
状态：用户已于 2026-09-22 确认首版范围

## 目标与已确认需求

让多位测试者使用独立账号，避免共享 admin 密码。普通用户可以配置自己的大模型，并持久保存关键工作数据。用户已选择“邀请码注册”。沿用 Vercel 前端、腾讯云 Python 后端和持久化 SQLite。

已确认首版关键数据范围：模型连接配置、命名设计方案（几何参数、工况、备注）、初始设计对话及候选方案。每项数据都可跨浏览器重新登录后恢复。管理员账号和现有数据必须保留。

## 方案选择

采用现有 SQLite 与会话认证的多用户扩展，按不可变 user_id 隔离数据。这样可以保留已有部署与管理员密码，避免引入外部认证服务。外部身份平台适合后续邮箱验证和第三方登录；为每位测试者部署一套服务维护成本较高，本次不采用。

## 注册与账号

- 登录窗口提供登录、邀请码注册两个入口。注册填写用户名、密码、确认密码和邀请码。
- 注册只能创建普通用户，客户端不能设置 role 或 user_id。用户名规范化后唯一，密码沿用至少 12 字符要求及加盐 PBKDF2 哈希。
- 邀请码由管理员在账号管理界面生成，一码一人，默认 7 天有效，可撤销。明文仅在生成时显示，数据库仅保存摘要。消费邀请码与创建账号在同一事务内完成，防止并发重复使用。
- 管理员可查看用户列表、禁用/恢复普通账号；禁用立即撤销会话。普通用户可修改本人密码，修改后撤销旧会话。首版不增加邮件服务或自助邮件找回。
- 继续使用 HttpOnly/Secure/SameSite Cookie 和 CSRF 校验；注册、登录、邀请码校验有请求体限制与服务端限流。反向代理下不信任客户端任意伪造的 IP 头。

## 数据与权限

- 身份由服务端会话确定，所有资源查询、写入、下载、删除均校验所有者，不能通过请求中的 user_id 选择其他用户。
- 每位用户独立配置通用与领域模型；配置查询仅显示是否存在密钥，不返回密钥明文。普通用户不继承服务器环境或管理员的模型密钥。
- 模型配置保存在腾讯云私有数据库中，沿用文件访问权限保护。首版不宣称数据库加密；后续若加入静态加密，需要独立密钥管理与恢复方案。
- 普通用户的模型请求仅允许公网 HTTPS，禁止回环、私网、链路本地、云元数据等目标，校验解析结果并确保实际连接目标一致，禁用重定向，避免 DNS 重绑定绕过。管理员现有私有模型用途单独保留权限边界。
- 个人工作区提供设计列表、保存、载入、重命名和删除；保存经过现有几何内核校验的参数及有限长度备注。对话以明确的“保存对话 / 打开对话”操作持久化，保留草稿恢复；不上传 API Key 到对话或导出文件。
- 初始默认配额：每用户 100 份设计、50 份对话；每份对话不超过 1 MiB。达到限制时清晰提示，不静默丢弃。
- 用户评估任务、数据集、代理模型及参数包使用独立目录，不能枚举或读取管理员现有任务。当前腾讯云是 model-only 模式，继续明确显示 CFD 不可用。
- 完整 CFD 服务的全局队列、机器令牌及调度设置仍仅管理员可用；首版不向普通账号开放共享 CFD 任务接口，避免借新增注册扩大现有计算权限。普通用户的个人设计与大模型测试不受影响。
- 同一浏览器切换账号时，清理模型表单、对话、当前方案、任务和列表缓存；浏览器恢复数据按用户分区。中途退出后的旧异步响应不得写入新账号页面或持久化存储。

## 后端结构与迁移

- 扩展 session_store：users、邀请摘要、个人模型配置、设计、对话表，session 关联不可变 user_id 与角色。
- 旧单管理员记录迁移为 admin 角色，保留密码哈希和模型配置；旧全局任务仍归管理员。迁移事务化、版本化且可重复启动，撤销旧会话并要求重新登录。
- 请求处理器解析身份后选择该用户的模型服务与个人目录，不修改一个全局 ModelService 的当前用户。并发上限同时考虑每用户与服务器总量。
- 增加注册、邀请码管理、用户禁用、个人密码、设计和对话 API；管理 API 强制 admin 角色，数据 API 强制所有者校验。
- 保留现有环境启动和本机首次初始化兼容。私有目录、邀请明文、数据库和测试凭据不得加入 Git 或部署静态文件。

## 前端

- 顶栏账号入口展示用户名，普通账号提供个人数据与修改密码，管理员额外提供用户和邀请码管理。
- 参数化设计提供“保存到我的设计 / 我的设计”，保留现有本地 JSON 导入导出。
- 初始设计提供对话保存、列表和恢复；切换账号时以新账号数据为准。
- 模型配置复用现有界面，明确属于当前用户。未配置时显示空状态，不展示管理员配置。

## 验收

1. 用户 A 使用有效邀请码注册成功，重复使用、过期和撤销邀请码失败，并发只能成功一次。
2. 用户 A/B 分别配置模型；真实代理测试使用各自密钥，均不能读取或覆盖对方配置。
3. A 保存设计与对话，服务重启后可恢复；B 无法通过列表或猜测 ID 读取、修改、删除 A 数据。
4. 普通用户不能调用管理员接口、获得管理员默认密钥或访问全局 CFD 目录；被禁用后旧会话立即失效。
5. 退出与账号切换后，旧请求、浏览器缓存和表单不串号。
6. 旧数据库迁移保留 admin 密码、配置及任务；备份恢复路径经过验证。
7. 运行 Python 身份/权限/迁移测试、前端会话与现有回归测试、Vercel 构建与发布包检查，再做浏览器端双账号联调。
